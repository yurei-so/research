# Labnote 017 multi-utterance candidate pool

This slice generates twelve whole-utterance Qwen candidates: four unseen conversational
sentences crossed with three broad reading recipes. The same seed, speaker, backend, and
generation settings are used throughout. No audio is edited.

Recipe identity will be hidden during annotation. The pool is for discovering whether
the Prosody 016 fingerprint structure survives new lexical content and contains enough
repeated labels to preregister a held-out retrieval evaluation.
