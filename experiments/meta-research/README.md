# Meta Research

Meta Research studies the apparatus, representations, and workflows used to
produce, preserve, evaluate, discover, and communicate Yūrei research.

Ordinary site maintenance is not Meta Research. Work belongs here only when it
states a research question, freezes a protocol, records observations, and
supports an interpretable result.

## Active experiment

- `meta-research-001` — grounded build-time labnote summarization. The experiment begins
  in private shadow mode; no generated summary is public merely because a model
  produced it.
