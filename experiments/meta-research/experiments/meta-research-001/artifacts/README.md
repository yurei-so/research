# META-RESEARCH-001 shadow artifacts

These eight candidate bundles correspond exactly to the frozen corpus. Every
candidate passed apparatus version `0.1.0` structural validation, which checks
schema, orientation length, exact source quotations, source hashes, and the
`no_new_claims` acknowledgement.

Structural validation is not factual review. Human review was stopped before
scoring because the candidates exposed a construct mismatch: they were compact
abstracts, not fast relevance orientations. The artifacts remain unchanged as
pilot evidence. No candidate is accepted, published, or eligible for toolkit
promotion. `frozen-protocol-v2.json` defines the replacement two-sentence target.
