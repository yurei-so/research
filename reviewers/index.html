Representative findings

  • prosody-018 · positive

    All twelve turn files were unique and passed the frozen mechanical duration checks. The isolated and conversation-aware assemblies were 12.61 and 13.25 seconds respectively.

  • zenith-017 · negative

    Aggregate exact accuracy was 11/16 (68.8%). Hero had 3 true positives, 8 true negatives, 5 misses, and no false positives. Inventory had 8 true positives, 6 true negatives, 2 false positives, and no misses. The promotion gate failed.

  • composition-009 · negative

    The valid campaign completed all 24 planned trials without failure. All eight complete triplets entered both blinded review sessions, with no automatic ties.

  • voxel-guidance-006 · mixed

    The temporal condition modestly improved depth error and discontinuity detection while modestly worsening free-space overlap. The run completed with exit code zero and empty stderr. The frozen result and scheduler receipt are retained under experiments/labnote006/.

Methods and limitations

We freeze protocols where documented, preserve failed results and distinguish synthetic tests from live and human-driven observations. Small samples, single reviewers and restricted artifacts limit external replication and generalization.
